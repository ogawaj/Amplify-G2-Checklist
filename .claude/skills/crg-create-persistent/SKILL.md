# 永続的ドキュメント作成

`doc/idea/` 配下のアイデアファイルをもとに、`doc/persistent/` 配下の永続的ドキュメントを作成します。

## 手順

以下の手順を **厳密に** 順番通り実行してください。

### Step 0: アイデアファイルの読み込み

1. `doc/idea/` ディレクトリ内のファイルを検索する
2. **ファイルが 1 つも存在しない場合は、以下の警告を出して処理を中断する：**

> ⚠ `doc/idea/` にアイデアファイルが見つかりません。
> 先に `doc/idea/` 配下にアイデアを記述したファイルを作成してください。

3. ファイルが存在する場合は、すべてのファイルを読み込み、内容を把握する

### Step 1: フォルダ準備

```bash
mkdir -p doc/persistent doc/steering
```

### Step 2: 永続的ドキュメント作成

`.claude/rules/document.md` の「永続的ドキュメント」セクションに従い、作成します。

**重要：** 1 ファイルごとに必ずユーザーの確認・承認を得てから次に進む。フィードバックがあれば修正する。

### Step 3: 完了報告

両ドキュメントが承認されたら、作成したファイルの一覧と次のステップ（ステアリングファイル作成）を案内してください。

## ルール

- アイデアファイルの内容が曖昧な場合は、ドキュメント作成前にユーザーに質問して明確化する
- その他のルール（技術スタック、図表記法、ファイル配置等）は `.claude/rules/document.md` に従う

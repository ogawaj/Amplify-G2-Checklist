  • amplify/functions/ をディレクトリごと削除

  • amplify/data/resource.ts から cklSayHello / cklAggregateAccess のカスタムクエリと import を削除
  • amplify/data/resource.ts のスキーマ末尾の .authorization((allow) => [allow.resource(cklAggregateAccess)]) を削除

フェーズE: 検証

  • DailyAccessSummary / cklSayHello / cklAggregateAccess / @shared の残存参照と、Todo の参照が resource.ts の定義以外にないことを grep で確認
  • npm run lint を実行
  • npx tsc --noEmit を実行
  • npx tsc --noEmit -p amplify/tsconfig.json を実行
  • npm run build を実行
  • amplify/common/ ・ amplify/auth/ ・環境変数一式・src/lib/shadcn/ が残っていることを確認

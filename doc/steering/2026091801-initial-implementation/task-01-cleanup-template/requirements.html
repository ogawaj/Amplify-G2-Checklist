Requirements

task-01: テンプレートのサンプルコード削除

サマリ

Amplify-G2-Template 由来のサンプルコード（Todo / DailyAccessSummary モデル、 ckl-say-hello / ckl-aggregate-access 関数、shared/、 およびそれらを参照するフロントエンドの Hook・Service・Repository）を削除し、CheckList の実装に必要な土台だけを残す。

機能追加は行わない。task-02 でモデルと画面を実装するための前準備にあたる。

ユーザーストーリー

  • 開発者として、サンプルモデルを削除したい。task-02 で4モデルを追加する際に amplify/data/resource.ts が二重管理にならないため
  • 開発者として、サンプル Lambda を削除したい。Lambda を持たない設計（functional-design.md §Lambda関数一覧）に合わせるため
  • 開発者として、shared/ とそのパスエイリアスを削除したい。フロントエンドとバックエンドで共有するコードが発生しない設計に合わせるため
  • 開発者として、サンプルを参照する Hook・Service・Repository を削除したい。参照先を失ったコードを残さないため
  • 開発者として、ホーム画面を最小構成に置き換えたい。削除後もアプリケーションが起動する状態を保つため

受け入れ条件

  • amplify/data/resource.ts に Todo / DailyAccessSummary と cklSayHello / cklAggregateAccess が存在しない
  • amplify/functions/ が存在しない
  • amplify/common/ は backend.ts が参照するため残っている
  • amplify/backend.ts から2関数の登録と環境変数注入ループが取り除かれている
  • amplify/backend.ts のパスワードポリシー設定とタグ付与は変更されずに残っている
  • shared/ が存在せず、amplify/tsconfig.json の @shared/* パスエイリアスも削除されている
  • src/app/ 配下に use-todo / use-access-summary / todo-service / access-summary-service / todo-repository / access-summary-repository が存在しない
  • 環境変数まわり（enums/env-variable-*.ts / models/env-variable.ts / services/env-variable-service.ts / hooks/use-env-variable.ts）は残っている
  • 削除したモジュールへの import がリポジトリ内に残っていない
  • npm run lint がエラー0で通る
  • npx tsc --noEmit と npx tsc --noEmit -p amplify/tsconfig.json がエラー0で通る
  • npm run build が成功する

制約事項

  • 本タスクでは削除のみを行う。CheckList の4モデル追加は task-02 のフェーズA で行う
  • amplify/auth/resource.ts は変更しない
  • ファイル削除は git rm を用いる（移動ではないため git mv は不要）
  • モデル削除は sandbox に反映すると既存テーブルが削除される。デプロイは task-02 のモデル追加とまとめて行い、本タスクでは必須としない
  • ホーム画面は task-02 のフェーズB・C で /lists への振り分けに置き換わる。本タスクでは最小限の表示に留める

CheckList 画面モック

doc/persistent/product-requirements.md の画面一覧（S-01〜S-09）に対応する静的モックです。 レイアウトと情報設計の確認を目的とし、操作・遷移は動作しません。配色やコンポーネントは実装時の確定仕様ではありません。 

S-01 サインイン ┬ S-02 サインアップ
                 └ S-03 パスワード再設定
  └ S-04 チェックリスト一覧（名称・日数・最終更新のみ／進捗は出さない）
       ├ カードをタップ → S-05 詳細（準備実行・チェックは行の右端）
       │    └ ⋯ メニュー ┬ S-06 持ち物編集（追加・修正・一括削除）
       │                  ├ S-07 カテゴリ管理（並び順・削除）
       │                  ├ S-08 タグ管理
       │                  └ S-09 CSV入出力（パソコンのみ）
       └ ヘッダー（パソコンのみ）→ S-09 CSV入出力

S-01 サインイン画面

F-12 認証 ／ スマートフォン ／ AC-06

S-02 サインアップ画面

F-12 認証（アカウント登録・確認コード） ／ AC-06

S-03 パスワード再設定画面

F-12 認証（確認コード・新パスワード） ／ AC-06

S-04 チェックリスト一覧画面

F-01 管理 / F-02 複製 ／ スマートフォン・デスクトップ ／ AC-01

S-05 チェックリスト詳細画面

F-06 フィルタ / F-07 チェック / F-08 一括リセット / F-09 数量計算 / F-10 日数 ／ AC-03〜AC-05

S-06 持ち物編集画面

F-03 持ち物（直接入力） / F-09 数量 / F-15 一括削除 ／ AC-02, AC-08

S-07 カテゴリ管理画面

F-04 カテゴリ管理（直接入力・並び順・紐付く持ち物があれば削除不可） ／ AC-10

S-08 タグ管理画面

F-05 タグ管理（直接入力・付与されていれば削除不可） ／ AC-11

S-09 CSV入出力画面

F-13 インポート / F-14 エクスポート ／ パソコン専用 ／ AC-09

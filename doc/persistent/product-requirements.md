# CheckList プロダクト要求定義書

## プロダクトビジョンと目的

### ビジョン

家族の外出準備を「毎回ゼロから思い出す作業」から解放する。持ち物リストを一度整備すれば、行き先と日数を指定するだけで「今回持っていくもの」がその都度組み上がる状態をつくる。

### 目的

- 出発前の準備において、**チェックの初期化・持ち物の取捨選択・必要数の暗算**という3つの反復作業をアプリ側に肩代わりさせる
- 乳幼児連れの外出のように持ち物点数が多く、抜けが発生すると現地で困る状況での**忘れ物ゼロ**を支援する

### 背景

現状はスマートフォン標準のメモアプリでチェックリストを運用している。項目数は100件規模に達し、以下の限界が顕在化している。

- チェックボックスを一括で解除する手段がなく、出発のたびに全項目を手作業で戻している
- 国内旅行・海外旅行・帰省など行き先によって必要な持ち物が異なるが、1枚のリストに混在しているため毎回読み飛ばしが発生する
- 消耗品の必要数は日数に比例するが、メモには固定の数字しか書けず、毎回頭の中で掛け算している

## ターゲットユーザーと課題・ニーズ

### ユーザー像

| 項目     | 内容                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 主利用者 | 乳幼児を連れて外出・旅行する保護者。持ち物リストの整備と準備実行の両方を担う |
| 副利用者 | 同居家族。整備済みのリストを見ながら準備を分担する                           |
| 利用端末 | 主にスマートフォン。出発直前に片手で操作する場面が中心                       |
| 利用頻度 | 旅行・帰省のたび（月1回程度）。準備期間中は1日に複数回参照する               |
| 想定人数 | 初期リリースでは1世帯（数名）                                                |

### 課題

| #    | 課題                                     | 詳細                                                                                       |
| ---- | ---------------------------------------- | ------------------------------------------------------------------------------------------ |
| P-01 | チェックを毎回手作業で外している         | 一括解除の手段がなく、出発のたびに数十〜100項目を1件ずつタップして未チェックに戻している   |
| P-02 | 行き先によって必要な持ち物が変わる       | 国内・海外・帰省で持ち物が異なるのに1枚のリストに同居しており、毎回目視で取捨選択している  |
| P-03 | 消耗品の必要数が日数に比例する           | おむつのように「1日あたりの必要数×日数」で決まる品目を、毎回暗算して数えている             |
| P-04 | 対象者ごとにリストを分けられない         | 子ども用・大人用などを別々のメモで管理すると、共通項目の整備が二重になる                   |
| P-05 | 長いリストをスマートフォンで追いきれない | 外出直前に確認する際、スクロール量が多く現在位置と残件を把握しづらい                       |
| P-06 | 既存リストの移行が手作業になる           | メモアプリに蓄積した100件規模の持ち物を1件ずつ手入力するのは負担が大きく、移行の障壁になる |
| P-07 | 大量の持ち物の整理・見直しが手間         | 不要になった持ち物を1件ずつ削除するのは煩雑で、まとめて手直しする手段がない                |

### ニーズ

- 準備開始時に**1操作でリストを初期状態に戻したい**
- 今回の行き先を指定するだけで**関係のない持ち物を視界から消したい**
- 日数を入力すれば**必要数が自動で出てほしい**
- 対象者や用途ごとに**複数のリストを持ちたい**。似たリストは一から作り直さず複製したい
- スマートフォンの画面で**まとまり（手荷物・食事・トイレなど）を保ったまま**閲覧したい
- 既存リストの移行時は**まとめて一括登録したい**。この作業はパソコンで行う
- 登録済みの内容を**取り出して表計算ソフトでまとめて直し、書き戻したい**
- 不要になった持ち物を**選んでまとめて削除したい**

## 成功の定義

1. 準備開始時のチェック初期化が**1操作**で完了し、手作業での解除がゼロになる
2. 行き先タグを選ぶだけで、その行き先に不要な持ち物が表示から除外される
3. 日数を入力すれば消耗品の必要数が表示され、利用者が暗算する場面がなくなる
4. 既存のメモアプリでの運用を完全に置き換え、移行後はメモアプリのチェックリストを参照しなくなる
5. スマートフォン1台で、準備実行に必要なすべての操作が完結する
6. 大量の持ち物の一括編集を、表計算ソフトとの往復で完結できる

## スコープ外（初期リリース）

以下は初期リリースでは実装せず、将来の拡張候補として保持する。

- 複数アカウントによるチェックリストの共有・権限管理（BR-04の実現）
- 外出単位の履歴管理（過去の旅行ごとの準備記録を残す機能）
- 持ち物・カテゴリのドラッグ操作による並べ替え
- 未チェックの持ち物のみを表示する絞り込み
- チェックリストの外部共有・印刷
- CSV入出力（F-13, F-14）のスマートフォン対応（パソコンからの利用のみを想定する）
- カテゴリ・タグ自体の一括削除（一括削除の対象は持ち物のみ）
- 通知・リマインダー
- オフライン利用（圏外・機内では利用できない）

## 受け入れ条件

### AC-01 チェックリスト管理（US-01〜US-06）

- 名称を指定してチェックリストを新規作成でき、作成後は一覧に表示される
- 一覧では各チェックリストの名称・日数・最終更新日時が確認できる
- 一覧には持ち物の件数や準備の進捗を表示しない（一覧を開くために持ち物を集計しない）
- チェックリストを複製すると、カテゴリ・持ち物・タグ付与・数量・並び順・日数が引き継がれる
- 複製されたチェックリストのチェック状態はすべて未チェックである
- チェックリストを削除すると、そのチェックリストに属する持ち物も併せて削除される
- 削除は確認操作を経てから実行される

### AC-02 持ち物の整備（US-02, US-07〜US-09, US-25）

- 持ち物には名称・所属カテゴリ・タグ・数量を登録できる
- 1件の持ち物に複数のタグを付与できる
- タグが1件も付いていない持ち物（以下「共通」）は、どのタグで絞り込んでも常に表示される
- 数量は「1日あたりの必要数」を任意で設定でき、未設定のままにもできる。設定する場合は正の整数のみを受け付ける（1〜999）
- 持ち物の追加は、詳細画面の編集モードで各カテゴリの末尾の追加欄から行い、続けて入力できる
- 持ち物の名称・数量・カテゴリ・タグ・並び順の変更と削除は、持ち物を選んで開く編集シートで行う
- 持ち物はカテゴリ内で並び順を変更でき、変更した順序が準備モードの表示順に反映される
- カテゴリとタグは、編集モードから開く管理シートで新規作成できる
- 追加した持ち物には、準備モードで選択中のタグを自動で付与しない

### AC-03 タグフィルタ（US-19）

- 行き先タグを選択すると、そのタグを持つ持ち物とタグ未設定の持ち物のみが表示される
- フィルタ適用中も、持ち物はカテゴリごとにまとまって表示される
- フィルタは解除でき、解除すると全持ち物が表示される
- 準備モードでは、表示される持ち物が0件のカテゴリを見出しごと非表示にする。編集モードでは空のカテゴリも見出しと追加欄を表示する
- 複数のタグを選択でき、選択中のタグは画面上で区別できる
- フィルタ適用中は、選択中のタグ名がスクロールしても見える位置に示される
- フィルタ適用中は、共通の持ち物にその旨が示される
- 編集モードではフィルタを適用せず、全持ち物を表示する

### AC-04 数量計算・日数設定（US-08, US-02, US-20）

- チェックリストに日数を設定でき、設定値は保存され次回参照時も維持される
- 日数の初期値は1で、1〜60の範囲で指定できる
- 日数は利用者が直接入力するか、増減の操作で1ずつ変更する（3泊4日の旅行であれば「4」にする）
- 「1日あたりの必要数」が設定された持ち物は、必要数が自動計算されて表示される
- 計算式は「1日あたりの必要数×日数」とする
- 画面には計算結果のみを表示し、算出根拠（1日あたりの必要数と日数）は読み上げで確認できる
- 数量が未設定の持ち物には数量を表示しない
- 日数を変更すると、表示中の必要数が即座に更新される

### AC-05 チェック操作・一括リセット（US-18, US-21, US-22）

- 持ち物をタップするとチェック状態が切り替わり、状態は保存される
- 一括リセットを実行すると、チェックリスト内の全持ち物が未チェックになる
- 一括リセットはタグフィルタの適用状態に関わらず、チェックリスト内の全持ち物を対象とする。フィルタ適用中は、表示されていない持ち物も対象であることと件数が示される
- 一括リセットは実行直後に元に戻せる
- 表示中の持ち物の残り件数が常に確認でき、チェック操作に追従して更新される。すべて準備済みになると準備完了が示される

### AC-06 認証（US-23, US-24）

- メールアドレスとパスワードでアカウントを登録でき、登録したアカウントでサインインできる
- パスワードを忘れた場合に再設定できる
- 未認証の状態で認証が必要な画面を開こうとするとサインイン画面へ誘導される
- サインインすると、そのアカウントに属するチェックリストのみが表示される
- サインアウトでき、サインアウト後は認証が必要な画面を参照できない
- 同一アカウントに複数の端末からサインインでき、いずれの端末からも同じ内容が参照できる

### AC-07 スマートフォン対応（P-05）

- スマートフォンの画面幅で横スクロールが発生せず、準備実行に必要なすべての操作が実行できる
- チェック操作の対象領域は、片手でタップして誤爆しない大きさが確保されている
- 画面幅に応じてレイアウトが切り替わり、タブレット・デスクトップでも破綻しない
- CSV入出力（F-13, F-14）への導線は、スマートフォンの画面幅では表示しない

### AC-08 持ち物の一括操作（US-11, US-12）

- 編集モードでは、操作対象を選ぶための選択欄が各行に表示される
- 選択欄は、準備状況のチェック（AC-05）と形で区別できる
- 全持ち物をまとめて選択・解除できる
- 1件以上選択すると、選択件数と一括操作（削除・カテゴリ移動・タグ付与）が表示される
- 選択した持ち物をまとめて削除・別のカテゴリへ移動・タグの付与と解除ができる
- 削除は確認操作を挟まずに実行し、実行直後に元に戻せる
- 選択が0件のときは一括操作を表示しない

### AC-09 CSVインポート・エクスポート（US-13〜US-17）

- チェックリストの持ち物をCSVファイルとして出力できる
- 出力される列は、取り込みに用いる列と同一であり、そのまま編集して取り込み直せる
- 出力ファイルは表計算ソフトで開いても日本語が文字化けしない
- CSVファイルを選択して取り込みを実行できる
- 取り込み対象は持ち物とし、1行が1件の持ち物に対応する
- 各行はカテゴリ名・持ち物名・1日あたりの必要数・タグを持ち、カテゴリとタグは名称が未登録であれば併せて新規作成される
- 取り込みは同期方式のみとし、CSVの内容をチェックリストの持ち物の正とする
  - 既存の持ち物と対応が取れる行は内容を更新する
  - 対応のない行は新規登録する
  - CSVに現れなかった既存の持ち物は削除する
- 取り込み実行前に、新規・更新・削除それぞれの件数と内容の一覧が確認できる
- 削除が発生する取り込みは、削除件数を明示したうえで確認操作を経てから実行される
- 形式不備の行は取り込まず、行番号と理由が一覧で示される
- 取り込み結果として、成功件数と失敗件数が表示される
- 更新された持ち物のチェック状態は取り込み前の状態を維持し、新規登録された持ち物は未チェックとする
- 識別子の列は出力されたまま編集しないよう、画面上で利用者に注意を示す
- 識別子を書き換えた行、または識別子を消した行は別の持ち物として扱われ、元の持ち物は削除・チェック状態は失われる

### AC-10 カテゴリ管理（US-03）

- カテゴリの一覧を、編集モードから開くカテゴリ管理シートで確認できる
- カテゴリの追加・名称変更・表示順の変更・削除は、カテゴリ管理シート上で直接行う
- カテゴリの表示順を変更でき、変更した順序がチェックリスト詳細画面の表示順に反映される
- 所属する持ち物が1件以上あるカテゴリは削除できず、削除できない理由が示される
- チェックリストに残る最後の1件のカテゴリは、所属する持ち物がなくても削除できず、削除できない理由が示される
- 削除するには、先に所属する持ち物を別のカテゴリへ移すか削除しておく必要がある
- 所属する持ち物がないカテゴリは確認操作を挟まずに削除され、実行直後に元に戻せる
- カテゴリを1件も持たないチェックリストは作れず、新規作成時に「未分類」カテゴリが1件用意される
- 同一チェックリスト内でカテゴリ名は重複できない

### AC-11 タグ管理（US-10）

- タグの一覧を、編集モードから開くタグ管理シートで確認できる
- タグの追加・名称変更・削除は、タグ管理シート上で直接行う
- 付与されている持ち物が1件以上あるタグは削除できず、削除できない理由が示される
- 削除するには、先に持ち物からそのタグを外しておく必要がある
- 付与されている持ち物がないタグは確認操作を挟まずに削除され、実行直後に元に戻せる
- 同一チェックリスト内でタグ名は重複できない

## 機能要件

### FR-01 チェックリスト管理

- チェックリストは名称を持ち、利用者が任意の件数を作成できる。名称の重複は許容する
- チェックリストは複製でき、複製時は元の構成（カテゴリ・持ち物・タグ付与・数量・並び順・日数）を引き継ぐ
- チェックリストの削除は、配下の持ち物ごと削除する

### FR-02 持ち物

- 持ち物は名称を必須項目として持つ
- 持ち物は1件のカテゴリに所属する
- 持ち物は0件以上のタグを持つ
- 持ち物は数量として「1日あたりの必要数」を任意で持つ。単位は持たず、未設定を許容する
- 数量を設定する場合の値は正の整数（1〜999）に限る
- 持ち物はチェックリストに属し、チェックリストをまたいで共有されない
- 持ち物はカテゴリ内の表示順を持つ。追加した持ち物はカテゴリの末尾に置かれる

### FR-03 カテゴリ

- カテゴリは名称を持ち、チェックリストごとに定義される。同一チェックリスト内で名称は一意とする
- カテゴリは表示順を持ち、詳細画面での表示順序を決定する
- カテゴリは追加・名称変更・削除・表示順の変更ができる
- 持ち物は必ずいずれかのカテゴリに所属するため、所属する持ち物が存在するカテゴリは削除できない
- チェックリストには常に1件以上のカテゴリが存在する

### FR-04 タグ

- タグは名称を持ち、チェックリストごとに定義される。同一チェックリスト内で名称は一意とする
- タグは行き先や用途など、絞り込みの軸として利用される
- タグは追加・名称変更・削除ができる
- 付与されている持ち物が存在するタグは削除できない
- タグは0件でもよい（タグを使わずに運用できる）

### FR-05 タグフィルタ

- 利用者はタグを選択して表示を絞り込める。複数選択した場合は、いずれかのタグを持つ持ち物を表示する
- タグを1件も持たない持ち物は「共通」と呼び、絞り込みの対象外として常に表示される
- 絞り込みは準備モードにのみ適用し、編集モードでは全持ち物を表示する

### FR-06 数量計算

- チェックリストは日数を保持する。初期値は1、指定できる範囲は1〜60とする
- 日数は利用者が直接入力する値であり、宿泊数からの換算は行わない
- 「1日あたりの必要数」が設定された持ち物は、日数を乗じた値を必要数として表示する
- 計算結果は表示のみに用い、持ち物に保存する値は「1日あたりの必要数」のままとする
- 数量が未設定の持ち物は、日数の影響を受けない

### FR-07 チェック状態

- チェック状態は持ち物ごとに保持され、端末を変えても引き継がれる
- 一括リセットはチェックリスト単位で全持ち物のチェック状態を未チェックにする

### FR-08 持ち物の一括操作

- 利用者は持ち物を複数選択し、まとめて削除・カテゴリ移動・タグの付与と解除ができる
- 選択の状態は編集モードを終えるか画面を離れると破棄され、保存されない
- 削除は実行直後に元に戻せる。元に戻せるのは直前の1操作のみとする

### FR-09 認証

- 利用者はアカウントを登録し、サインイン・サインアウトできる
- 利用者はパスワードを再設定できる
- データは所有者のアカウントに紐づき、他アカウントからは参照できない

### FR-10 CSVインポート・エクスポート

- 出力と取り込みは同一の列構成を用い、出力したファイルを編集してそのまま取り込める
- 1行は「持ち物の識別子・カテゴリ名・持ち物名・1日あたりの必要数・タグ（複数可）」で構成される
- 識別子は出力時に付与され、取り込み時に既存の持ち物との対応付けに用いる。空欄の行は新規登録として扱う
- カテゴリ名・タグ名が未登録の場合は、取り込みの過程で新規に作成される
- 取り込みは同期方式のみとし、取り込み後のチェックリストの持ち物はCSVの内容と一致する
- 取り込みは確認のうえ実行し、形式不備の行は行単位で除外して結果を報告する
- 形式不備で除外された行に対応する既存の持ち物は、削除せず取り込み前の状態を維持する
- CSV入出力はパソコンからの利用のみを想定し、スマートフォンでは導線を提供しない

## 非機能要件

### パフォーマンス目標

| 項目                     | 目標                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| チェックリスト詳細の表示 | 持ち物150件規模で、操作可能になるまで2秒以内                         |
| チェック操作の反応       | タップから表示反映まで即時（操作結果を先に画面へ反映する）           |
| タグフィルタ・日数変更   | 再表示まで1秒以内                                                    |
| 一括リセット             | 持ち物150件規模で3秒以内に完了する                                   |
| CSVインポート            | 200行規模のファイルで、確認表示まで3秒以内・取り込み完了まで10秒以内 |
| CSVエクスポート          | 200行規模のチェックリストで、ファイル出力まで5秒以内                 |
| 持ち物の一括削除         | 選択100件規模で5秒以内に完了する                                     |

### セキュリティ要件

| 項目               | 要件                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| 認証               | 認証を経ないとチェックリストの参照・編集ができない                       |
| 認可               | データは所有者アカウントに紐づき、他アカウントからの参照・編集を拒否する |
| 通信               | 通信経路は暗号化する                                                     |
| 認証情報の取り扱い | パスワード等の認証情報を平文で保存・表示しない                           |
| 入力値             | 利用者の入力値は表示時に無害化し、意図しないスクリプト実行を防ぐ         |
| ファイル取り込み   | 取り込むファイルは形式と行数の上限を検証し、想定外の内容を登録しない     |
| ファイル出力       | 出力できるのは所有者本人のチェックリストに限る                           |

| 対応端末の限定   | CSV入出力（F-13, F-14）はパソコンからの利用に限定し、スマートフォンでは導線を表示しない                                             |
